# Omnirace

OmniRace is an elite, high-performance tactical ocean racing command and vessel telemetry system. Designed for ultra-endurance transoceanic regattas (such as foiling IMOCA 60 monohulls and Ultim 32/23 Trimarans competing in the tropical South Pacific & Coral Sea — from Tahiti to Fiji via the Cook Islands, Tonga, and the Great Astrolabe Reef). The platform bridges aerospace-grade vessel telemetry, computational meteorology, nautical navigation, and race analytics into a unified, visually arresting marine dashboard.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- lucide-react, clsx

## Getting Started

1. Install dependencies
   - npm install

2. Development
   - npm run dev

3. Build for production
   - npm run build

4. Preview production build
   - npm run preview

## Project Structure

- src/        - Source React components
- index.html  - Entry HTML
- dist/       - Production build output
